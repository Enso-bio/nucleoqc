# Co-isolated nucleic acid in public proteomics data — analysis code

Analysis code and input tables for the article *"Co-isolated nucleic acid in public proteomics data: prevalence, association with peptide identification, and a quality-control tool"*. The quality-control tool is the `nucleoqc` package in the parent folder (install it first: `pip install ..`).

All data are public in PRIDE. Scripts read PRIDE files by HTTPS range requests (three 4 MB chunks per file). Peptide searches use Sage 0.14.7 and Comet 2026.03.0 (paths passed on the command line). Python 3.12 with numpy, scipy, statsmodels, pandas, matplotlib and openpyxl.

## Running the scripts

Run the scripts from this folder. Steps that only read the included tables run offline: `atlas_analysis.py`, `protocol_annotation.py analyse`, `sensitivity.py`, `identifications_analysis.py _1p`, `impact_analysis.py`, `nuclease_analysis.py`, `nuclease_cross_section.py analyse`, `nucleoqc_calibration.py`, `supplementary_tables.py` and `figures.py`.

Steps that search or re-read spectra need network access to PRIDE, and Sage 0.14.7 or Comet 2026.03.0 where stated. They keep the spectra read from PRIDE (`.pkl`), the mzML files written for Sage and the Sage results in a work folder: `search_work/` in this folder, or the folder given by the `NUCLEOQC_SEARCH_WORK` environment variable. Later steps (`matching.py`, `quantification.py`, `base_panel.py`, `table_s10.py`, `rescue_analysis.py`, `comet_search.py`) read that folder, so run `identifications.py` first.

## Data files

Tables are tab-separated with English column names; they are the same tables, with the same column names, as the sheets of `Supplementary_Tables.xlsx`. `nb10` / `nb2` = fraction of MS2 spectra with adenine or guanine ≥10 % / ≥2 % of the base peak; `nb` in `ids_spectra_1p.tsv` = nucleobase intensity relative to the base peak for each spectrum.
